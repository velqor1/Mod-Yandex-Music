# Мод оригинального Android APK

Текущий выпуск: **0.6.4-alpha.1** на базе Яндекс Музыки **2026.11.1 #171rur**. Оригинальные аккаунт, навигация и движок воспроизведения сохранены. Отдельный экспериментальный клиент из `mobile/android/` не используется.

## Возможности

Красный знак и собственные настройки мода, AMOLED и пресеты, стеклянные элементы управления, двухвкладочная навигация, таймер сна, локальные история и статистика. Тексты загружаются из доступных источников; синхронизация есть при наличии настоящих таймкодов. Менеджер массового редактирования коллекции, умные папки и статистика жанров пока не входят в сборку. Полное описание и скриншоты — в основном README.

## Сборка

```powershell
python -X utf8 mobile/apkmod/build.py
```

Нужны Python 3, JDK 21, Android SDK 36 / build-tools 36.0.0 и APKTool 3.0.3. Путь SDK можно задать через `ANDROID_HOME`, JDK — `JAVA_HOME`.

- Исходный APK: `build/apk-source/yandex-music-2026.11.1.apk`, SHA-256 `5c6eacb12957ef9b25dd8e9ba1fd33876f8cff55a2894d00ba62511649d5ba4f`.
- APKTool: `tools/apktool_3.0.3.jar`, SHA-256 `dbf930b076c6b9be08d57c449cacefc3bdd6b71ebd59b3066fc0e1f5b14f9423`.
- Чистая распаковка — `build/apkmod/upstream`, рабочая копия — `build/apkmod/work`. Для AAPT2 на Windows используется временный ASCII SUBST-диск.
- Результат и отчёт — `dist/android-apkmod/`. Компилируется helper DEX и изменённые native DEX; проверяются подпись и zipalign 16KB.
- `--reuse-work` ускоряет повторную сборку. Без него рабочая копия готовится из чистой исходной базы. Изменение версии обновляет скомпилированный manifest.

Подпись не подменяется оригинальной подписью Яндекса. Ключ не входит в репозиторий. Для обновления поверх уже установленного опубликованного мода нужен тот же ключ; собственный APK с другим ключом поверх него не установится.

## Структура

`ModRuntime` — lifecycle и настройки; `ModUi` / `ModGlass` — материал и элементы; `ModBottomNav` — представление штатного tab controller; `NavMotion` / `NavRequests` — движение и последовательность запросов. `ModNativeUi` работает с Compose semantics самого клиента, без AccessibilityService.

`ModListening` / `ListeningClock` — локальные события и агрегаты. `ModTrackAssets` / `TrackIdentity` — обложки и проверка соответствия записи. `ModPlayback` использует только MediaSession этого APK. `ModTimerService` ставит воспроизведение на паузу, собственного аудиоплеера нет.

`ModLyrics` использует публичную метаинформацию трека, supplement, LRCLIB и доступный резервный обычный текст. Внешним источникам передаются название и исполнители для поиска; OAuth-токены дополнение не читает. HTTP403 источника не обходится. Отсутствующие таймкоды не синтезируются.

`ModChrome` скрывает известные типы вкладок и промоэлементов; это не глобальный сетевой блокировщик рекламы.

## Совместимость авторизации

Passport использует изолированный тип `com.yandex.passport.wl.musicmod`. Его prefix `.wl` и исходные валидаторы SDK необходимы для работающего входа. Не переобъявляйте общую signature-permission `com.yandex.permission.READ_CREDENTIALS`. Не очищайте данные и не удаляйте Яндекс-приложения при обновлении.

## Проверки

- Чистые Java-тесты `NavMotionTest`, `NavRequestsTest`, `ListeningClockTest`, `TrackIdentityTest` компилируются с одноимёнными helper-классами.
- SQL: `python -m unittest discover -s mobile/apkmod/tests -p "test_*.py"`.
- Сводка проверок выпуска — `docs/RELEASE_CHECKS_RU.md`; инструкции для обеих платформ — `docs/BUILD_RU.md` от корня репозитория.

В некоторых исходных DEX уже достигнут лимит method references; добавление вызовов требует проверки лимита и распределения классов. Готовые APK, распаковка клиента, ключи и локальные данные не коммитятся.
